# test2

シンプルな Flask 製のチャット試作アプリです。`高難易度.txt` の内容を参照し、医師から言われた内容に対する返答例を提案します。

## 起動方法

```bash
python -m pip install -r requirements.txt
python app.py
```

ブラウザで `http://127.0.0.1:5000` を開いて利用してください。
`SECRET_KEY` を設定しない場合は起動ごとに一時キーを生成するため、将来セッション機能を追加した場合は再起動でセッションが引き継がれません。

## 参照ファイル

- リポジトリ直下の `高難易度.txt` を読み込みます
- 実際の面会記録がある場合は、このファイルを置き換えてください
- 参照内容を差し替えた場合は、アプリを再起動すると新しい内容が反映されます
